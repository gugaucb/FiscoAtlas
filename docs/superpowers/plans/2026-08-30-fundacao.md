# Fundação (Plano 1/6) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold Django monolito em Docker com PostgreSQL, modelos de configuração (TaxRule versionada por ano, Asset, BrokerAccount, PtaxRate) e PtaxService funcionando ponta a ponta (consulta BCB, cache, fallback configurável, override manual auditável).

**Architecture:** Monolito Django single-user (ADR-0002) com apps por domínio: `fiscal` (regras tributárias como dados — ADR-0001), `fx` (PTAX), `ledger` (ativos, contas, eventos). Cálculos em `Decimal`, nunca float (spec §37). Sem `usuario_id` — usuário único (ADR-0002).

**Tech Stack:** Python 3.12, Django 5, PostgreSQL 16, Docker Compose, pytest + pytest-django, `httpx` para chamadas ao Banco Central.

**Spec:** `PROJETO — SISTEMA DE APURAÇÃO DE IRPF PARA INVESTIMENTOS NO EXTERIOR.md` (seções 4, 6–8, 23, 37), `CONTEXT.md` (glossário), `docs/adr/0001-regras-tributarias-como-dados-versionados.md`, `docs/adr/0002-single-user-local-first.md`

## Global Constraints

- Precisão monetária: `DECIMAL(20,8)` valores, `DECIMAL(24,10)` quantidades, `DECIMAL(12,8)` PTAX — exatos, do spec §37.
- Nunca float/double para valores monetários (spec §37).
- Regras tributárias são dados no banco com `tax_year` + `rule_version`, nunca constantes no código (ADR-0001, spec §4).
- Tabela progressiva default 2024+: isenção até R$ 6.000, 15% de 6.000,01 a 50.000, 22,5% acima de 50.000 — **marcada `confirmed=False` (a validar com contador)**.
- PTAX fiscal: cotação de **venda** (`quote_type=VENDA`) como default configurável, **`confirmed=False`** até validar com contador.
- Fallback de PTAX nunca é silencioso: `requested_date` ≠ `effective_date` fica registrado e visível (spec §23).
- Eventos financeiros nunca são apagados; correções = nova versão (spec §9).
- Sem multi-tenancy: nenhum modelo tem `usuario_id` (ADR-0002).
- Todos os testes rodam com `docker compose run --rm app pytest` (nada de dependências Python na máquina host).

```python
from django.db import models


class TaxRuleQuerySet(models.QuerySet):
    def for_year(self, year: int) -> "TaxRule":
        rule = (
            self.filter(tax_year=year, confirmed=True)
            .order_by("-rule_version")
            .first()
        )
        if rule is None:
            raise ValueError(f"Sem TaxRule confirmada para o ano {year}")
        return rule


class TaxRule(models.Model):
    tax_year = models.PositiveIntegerField()
    rule_version = models.CharField(max_length=64)
    brackets = models.JSONField()  # [{"limit_brl": "6000.00"|None, "rate": "0.15"}]
    foreign_tax_credit_enabled = models.BooleanField(default=True)
    loss_carryforward_enabled = models.BooleanField(default=True)
    fx_cash_policy = models.JSONField(default=dict)  # política de caixa não remunerado
    quote_type = models.CharField(max_length=10, default="VENDA")
    confirmed = models.BooleanField(default=False)
    effective_from = models.DateField()
    effective_until = models.DateField(null=True, blank=True)

    class Meta:
        constraints = [
            models.UniqueConstraint(
                fields=["tax_year", "rule_version"], name="uniq_taxrule_year_version"
            )
        ]
```

```python
class PtaxRate(models.Model):
    QUOTE_TYPES = [("VENDA", "PTAX venda"), ("COMPRA", "PTAX compra")]

    effective_date = models.DateField()

                condition=models.Q(manually_overridden=False),
                name="uniq_ptax_effective_quote",
            )
        ]

    def __str__(self):
```

`fx/service.py`:
```python
from datetime import date, timedelta
from decimal import Decimal

import httpx

from fx.models import PtaxRate

BCB_URL = (
    "https://olinda.bcb.gov.br/olinda/servico/PTAX/versao/v1/odata/"
    "CotacaoDolarDia(dataCotacao=@dataCotacao)?@dataCotacao='{dd-mm-yyyy}'"
    "&$format=json"
)


class PtaxService:
    def get_rate(self, requested: date, quote_type: str = "VENDA") -> PtaxRate:
        cached = PtaxRate.objects.filter(
            requested_date=requested, quote_type=quote_type, manually_overridden=False
        ).first()
        if cached:
            return cached
        effective = requested
        while True:
            data = self._fetch_bcb(effective)
            if data["value"]:
                return PtaxRate.objects.create(
                    requested_date=requested,
                    effective_date=effective,
                    quote_type=quote_type,
                    rate=Decimal(str(data["value"][-1][f"cotacao{quote_type.capitalize()}"])),
                )
            effective -= timedelta(days=1)

    def _fetch_bcb(self, day: date) -> dict:
        resp = httpx.get(BCB_URL.replace("{dd-mm-yyyy}", day.strftime("%d-%m-%Y")), timeout=30)
        resp.raise_for_status()
        return resp.json()
```

Nota: `CotacaoDolarDia` retorna vazio (`value: []`) em dias sem cotação — o loop recua. Cache por `requested_date` evita chamadas repetidas (spec §23).

```python
from django.db import models

ASSET_TYPES = [("STOCK", "Ação"), ("ETF", "ETF"), ("REIT", "REIT"), ("BOND", "Bond"), ("FUND", "Fundo"), ("OTHER", "Outro")]
ACCOUNT_TYPES = [("CASH", "Cash"), ("CUSTODY", "Custódia"), ("MARGIN", "Margem"), ("OTHER", "Outro")]


class Asset(models.Model):
    ticker = models.CharField(max_length=32, unique=True)
    description = models.CharField(max_length=255)
    asset_type = models.CharField(max_length=10, choices=ASSET_TYPES)
    isin = models.CharField(max_length=12, null=True, blank=True)
    currency = models.CharField(max_length=3, default="USD")
    country_code = models.CharField(max_length=2, default="US")
    active = models.BooleanField(default=True)


class BrokerAccount(models.Model):
    broker_name = models.CharField(max_length=128)
    account_number = models.CharField(max_length=64)
    country_code = models.CharField(max_length=2, default="US")
    currency = models.CharField(max_length=3, default="USD")
    account_type = models.CharField(max_length=10, choices=ACCOUNT_TYPES, default="CASH")
    is_interest_bearing = models.BooleanField(default=False)
    active = models.BooleanField(default=True)
```
